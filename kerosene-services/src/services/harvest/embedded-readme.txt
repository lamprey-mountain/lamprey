this is a harvest (data export) generated by a lamprey server.

every `*.json` file contains a single json object.
every `*.ndjson` file contains one json object per line.

layout:
  harvest.json                                  metadata about this harvest and the server it came from
  media.ndjson                                  metadata of every media object referenced below, by id
  users.ndjson                                  every user referenced by this archive
  audit-log.ndjson                              audit log entries of the exported user (user harvests only)
  rooms/<room_id>/room.json                     the room, its roles and its channels
  rooms/<room_id>/emojis.ndjson                 custom emojis of the room
  rooms/<room_id>/members.ndjson                members of the room
  rooms/<room_id>/audit-log.ndjson              audit log entries of the room
  channels/<channel_id>/channel.json            the channel
  channels/<channel_id>/messages.ndjson         messages, oldest first
  channels/<channel_id>/versions.ndjson         all versions of the messages above
  channels/<channel_id>/reactions.ndjson        reactions on the messages above

notes:
- user harvests only contain the messages the user has sent, plus the reactions
  they have sent in channels that are part of the archive
- media objects embedded in messages are replaced by their id; the full
  object is in media.ndjson
- only media metadata is included, not the files themselves. fetch them from
 `<cdn_url>/media/<id>` of the server this archive came from
- deleted messages and removed channels may be included, indicated by the
 `deleted_at`/`removed_at` fields
